# Playground evidence — September 9, 2026

Actual application renders from our own isolated headless Chromium process on Windows. Temporary Playwright contexts only; no personal browser, desktop input, OS capture, paid generation or account changes.

- `baseline-home.png`, `baseline.json`: production v0.4.1 baseline before implementation.
- `final-harbor-warehouse.png`, `final-harbor-covered.png`, `final-harbor-tanks.png`, `final-harbor-waterfront.png`, `final-harbor-night.png`: final code, day/night Free Ride driven through actual input and simulation.
- `harbor-gameplay-silent.mp4`: 24-second excerpt of the final headless Harbor drive, 960×600, no audio track. Not a desktop recording or generated concept video.
- `home.png`, `harbor-briefing.png`, `harbor-cockpit.png`, `drift-briefing.png`, `original-race.png`, `mobile-*.png`: final mode navigation, controls, cockpit, preserved race grid, mobile layout. `headless-checks.json` records the assertions.
- `drift-result.png`, `controlled-slide-*.png`, `guided-drive.json`: complete 90-second Drift Attack in the working checkpoint before the final Harbor prop/clock-start polish. Score 1,624; saved under `harbor-easy-day-drift-v1`, zero campaign credits/chapter changes, no runtime errors. Actual analog input and a virtual standard-gamepad adapter; no score or pose injection. Earlier `harbor-day-driving.png`, `harbor-underpass.png` and `harbor-waterfront.png` show that checkpoint (the old underpass frame is after exiting).
- `final-visuals.json`: final bundle identity, five driving snapshots, wheel positions, contacts and frame profile. The final driving run captured 2,710 active-frame intervals: p50 16.7 ms, p95/p99 16.8 ms, max 33.4 ms, five above 33.34 ms. Selected Harbor frames show 169–180 draw calls and 300,425–353,149 submitted triangles including renderer passes. This is headless WebGL/ANGLE timing, not GPU time or a mobile benchmark. The event clock excludes initial scene preparation. Wheel-center height minus contact/radius error was below 1e-12 m across the captured snapshots.
- `startup-pause.json`, `initial-visual-timeout.json`, `failed-visual-drive.png`: retained failed evidence. A 683 ms initial render caused Free Ride to auto-pause at 0.0167 seconds. The first event render now completes before simulation time starts; subsequent long-frame protection remains. `final-visuals.json` is the passing repeat.
- `tests.json`: 113 tests, including all six route integrations, steering sign, grip/brakes, collision direction, drift abuse/combo/timer, save compatibility and reward idempotency. `../simulation-results.json` contains the route/contact diagnostics.

Reproduce after `npm run build` and `npm run preview -- --port 4173`: `node scripts/headless-playground.mjs`, `node scripts/headless-guided-drive.mjs` (full attack), or `node scripts/headless-guided-drive.mjs --visuals` (final port views). These launch headless Chromium; set `HEADLESS_CHROMIUM` to an existing headless executable if needed. Raw videos stay in ignored `raw/`.

Mobile evidence is 390×844 touch/reduced-motion emulation. No new physical-phone/controller, WebGPU-runtime, human audio-listening or GPU-timing claim. Existing audio retained; only a restrained existing tone provides token feedback. Port geometry, its 256×256 corrugation canvas, and road-detail meshes are original procedural artwork in `src/harbor.ts` / `src/road-details.ts`; no downloaded or paid assets added.
