# Owner-supplied reference refinement

Source: `D:\slingshot angles`, shared by the owner September 9, 2026. The folder contains 2025 R Granite Gray and S Havasu Red angle sequences; the R sequence guides the existing R-inspired game model. Reference PNGs remain external and are not embedded in the game or republished. Paint colors are not restricted to the reference finish.

Inspected R frames 0000 (side), 0009 (rear), 0018 (opposite side), 0027 (front). The source PNGs are 3840×2160. This is visual interpretation, not photogrammetry or manufacturer CAD.

Implemented in the existing Blender generator:

- Continuous tapered bucket seats, integrated headrest silhouettes, dished cushions, raised hip bolsters and restrained contrast seams.
- Two longitudinal hood channels and central shoulders, with a more integrated center-light eyebrow.
- Recessed outer optics with painted eyelids and small lens divisions, preserving the bright night-light material contract.
- Rear shoulder deck, center tail spine, angular wraparound tail lamps, lower closeouts and a visible rear coil spring.

Existing axle positions, collision/drivetrain parameters, steering pivots, paint/RGB palette, rim/exhaust choices, save schema and tracks are unchanged. The source model and both shipped GLBs are rebuilt; simplified fallback geometry is retained.

Before/after neutral renders use the same camera and studio. Before frames are in `evidence/reference-refinement/`; current frames and refreshed turntable are in `artwork/vehicle/`. The live game must additionally verify customization, light visibility, cockpit clearance and reduced-detail decoding.

The user approved the general previous model direction. This refinement preserves that foundation; it still does not establish OEM dimensional accuracy or owner approval of every new contour.
